# App Store Connect declaration worksheet

This worksheet is preparation, not an assertion that the fields have been entered or accepted in App Store Connect.

- Platform: iOS, iPhone and iPad. Primary language: English (U.S.).
- Intended price: free. No in-app purchases or subscriptions.
- Intended distribution: all available territories subject to the publisher's legal eligibility and regional requirements. EU trader status requires the actual publisher's truthful determination and, if required, verified contact information.
- Category draft: Education primary, Medical secondary.
- Login/demo account: none required. All learning features use bundled data.
- App privacy draft: the native build does not collect data, track users, or include analytics/advertising SDKs. User-initiated JSON exports and optional external browser links are described in the policy. Re-evaluate if the final binary changes.
- Encryption draft: app does not implement proprietary or nonexempt encryption. External links open the system browser. Final export-compliance responses must match the distributed binary.
- Content rights: the authored curriculum is original. USMLE/NBME questions and proprietary screenshots were not copied. Professional reference pages are linked rather than redistributed. Publisher must confirm rights and branding for the final app.
- Age-rating questionnaire: answer accurately for frequent educational medical information. The app has no ads, user chat, user-generated content feed, gambling, simulated gambling, violence, sexual content, substance-use entertainment, or unrestricted in-app web browser. Do not guess the resulting numerical rating; let Apple's current questionnaire compute it.
- Medical purpose: education only; no diagnosis, treatment, monitoring, HealthKit, patient records, clinical decision support, or device accessory.
- Medical review: independent expert approval and complete item-level source verification are pending. No certification is claimed.
- Required review contact: actual first name, last name, email, phone.
- Required publisher/copyright details: actual legal entity or individual; not a generated identity.
- Screenshots: use real screenshots from the iPhone and iPad native build in Apple's currently accepted sizes. No web mockups or simulator-only build claimed as a signed release.
- Release method: manual release after Apple approval, so review submission does not automatically launch the app.
