## 7. Age Rating

**Recommended rating: 4+** — the game itself has no objectionable content (no violence, no mature themes, no user-generated content, no unrestricted web access).

However, the Age Rating questionnaire in App Store Connect and the separate **App Privacy ("Nutrition Label")** section still need entries that reflect the advertising SDK, even at a 4+ rating:

**Age Rating questionnaire:**
- Answer "Yes" to the question about the app containing advertising / third-party analytics, since AdMob is integrated.
- Do not select "Made for Kids" — the app is general-audience, not a kids' category app (see Section 8 of the Privacy Policy).

**App Privacy ("Nutrition Label") — data types to declare, given AdMob:**
- **Identifiers > Device ID** (the advertising identifier, IDFA) — collected, linked to the user only when tracking is authorized, used for **Third-Party Advertising** and **Analytics**.
- **Usage Data** (ad interaction/impression data collected by AdMob) — used for **Third-Party Advertising**, **Analytics**, and **Developer's Advertising or Marketing**.
- **"Used to Track You" toggle:** set to **Yes** for the Device ID entry, reflecting that AdMob can use the identifier to track users across apps/websites of other companies when the user grants App Tracking Transparency permission. If tracking is declined, the identifier is not used for that purpose for that user, but the *capability* still needs to be declared honestly in the Nutrition Label because the SDK is present and requests the permission.
- No other categories (Contact Info, Health & Fitness, Location, Financial Info, User Content, etc.) apply, since none of that data is collected.

Consult Apple's current App Privacy documentation and AdMob's own "App Privacy details for App Store" guide when filling out the questionnaire, since Apple periodically renames categories.
